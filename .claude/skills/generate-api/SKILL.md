# generate-api

Keeps the API layer honest against `openapi.auctions.v0.json` (repo root — the source of truth). Two things are generated, one is hand-written to match a stable shape:

1. `shared/api/generated/*` — fully generated by `@hey-api/openapi-ts`, safe to regenerate and overwrite freely.
2. `shared/lib/api/generated/{queries,mutations,invalidations}.ts` — hand-written today (one `useXxx = createQuery(xxxQuery)` / `createMutation` / `invalidateQuery` line per operation in `shared/api/generated/@tanstack/react-query.gen.ts`), because the external hook-generator package isn't published yet.

## Steps

1. Run `npx @hey-api/openapi-ts` (config in `openapi-ts.config.ts`) against `openapi.auctions.v0.json` → refreshes `shared/api/generated/*`. Safe to run any time the schema changes; never hand-edit files under `shared/api/generated/`.
2. Check whether an external generator package (name TBD once published — check `package.json` devDependencies for something like `openapi-tsq-codegen`) is installed:
   - **If installed**: invoke it instead of doing step 3 by hand, pointing it at `shared/api/generated/@tanstack/react-query.gen.ts` with output `shared/lib/api/generated/`. This replaces the hand-written step below entirely.
   - **If not installed** (current state): do step 3.
3. Diff the exported operation names in `shared/api/generated/@tanstack/react-query.gen.ts` against what's already wired in `shared/lib/api/generated/{queries,mutations,invalidations}.ts`:
   - New operation → add one `createQuery`/`createMutation` line (see existing lines for the exact pattern) + one `invalidateQuery` line if it's a query.
   - Removed operation → remove its lines, and grep the codebase for any remaining usage before deleting (a removed endpoint with live callers is a real break, not just cleanup).
   - Renamed operation → rename the corresponding `useXxx`/`invalidateXxx` export, then grep for the old name across `entities/*/api` and fix call sites.
4. Report what changed in plain terms (new/removed/renamed operations) rather than silently rewriting everything — this wiring is hand-maintained until the external package lands, so unexplained bulk diffs are a red flag, not routine.
